AgBioDatabase Finder helps researchers select domain-specific databases by organism and data type. Its database profiles use ontology mappings and link to submission guidance to support data deposition, discovery, and reuse.

**Relevance to FAIR bioHeaders:** The tool provides context for where genomic data can be deposited and discovered; FAIR bioHeaders addresses the metadata carried with the files themselves.
