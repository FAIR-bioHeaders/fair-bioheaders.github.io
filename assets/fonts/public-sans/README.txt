# Public Sans

Unmodified WOFF2 files from the official USWDS Public Sans v2.001 release:
https://github.com/uswds/public-sans/tree/v2.001/fonts/webfonts

Included faces: Regular (400), SemiBold (600), ExtraBold (800), and Italic (400).
These match the weights and styles previously requested from Google Fonts.
